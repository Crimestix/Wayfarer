# Texturen der Dungeonkarte

Alle Dateien in diesem Ordner stammen von **Poly Haven** (polyhaven.com) und stehen unter **CC0**
(gemeinfrei, keine Namensnennung nötig). Sie sind auf 512 Pixel verkleinert und auf die Farben der
Karte abgestimmt; Wasser, Säure und Lava sind aus Steintexturen umgerechnet.
