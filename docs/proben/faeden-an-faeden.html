Fäden an Fäden

Kein Baum, sondern ein Netz: Jeder Faden kann mit jedem anderen verbunden sein, Faden für Faden. Duskryns Arena gehört zu Vorzagath, ist aber zugleich mit Fäden verbunden, die woanders hingehören. Aus diesen Verbindungen entsteht auf dem Brett das Spinnennetz.

Gebaut ist noch nichts. Alles in Klammern steht für deinen eigenen Wortlaut, Wayfarer erfindet davon nichts.

Der Gedanke

  1. Faden an Faden. Du verbindest zwei Fäden, egal ob sie zur selben Geschichte gehören, zu verschiedenen oder zu keiner. Eine Verbindung darf ein Wort tragen („führt zu“, „wer dahintersteckt“), muss aber nicht.

  2. Ein Hinweis kann zu einem Faden führen. Ein Hinweis in der Arena zeigt auf einen anderen Faden. Findet die Gruppe ihn, weiß Wayfarer, wohin die Spur jetzt geht. So wird aus den Hinweisen ein Weg durchs Netz.

  3. Jeder Faden gehört höchstens zu einer Geschichte. Die Verbindungen gehen quer durch. Hängen Fäden zweier Geschichten zusammen, zeigt das Brett auch die Geschichten als verbunden, abgeleitet und nie von Hand gezogen.

  4. Nichts geschieht von selbst. Wayfarer schlägt höchstens vor, was zusammenpassen könnte, etwa Fäden mit demselben Ort oder derselben Person. Verbinden tust du.

So sähe das Brett aus

Eine Geschichte lässt sich aufklappen: Dann hängen ihre Fäden als Knoten an ihr. Verbundene Fäden halten Schnüre zusammen, Namen hängen an den Fäden, die sie betreffen.

Fragen an dich

1. Ist das das Netz, das du meinst?Fäden quer verbunden, dazu Hinweise, die zu einem Faden führen.
2. Brett: Fäden als eigene KnotenMein Vorschlag: Eine Geschichte klappst du auf, dann hängen ihre Fäden an ihr. Fäden mit Verbindungen nach außen stehen immer da, sonst sähe man das Netz nicht.
3. Ein Wort an der VerbindungFreiwillig, frei geschrieben, so wie die Rollen auf dem Blatt. Oder lieber ganz ohne?
4. Wie weit am Spieltisch?Mein Vorschlag: der Faden am Ort und genau ein Schritt weiter. Das ganze Netz gibt es nur auf dem Brett.
