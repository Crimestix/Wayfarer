# Abgleich ausprobieren – Anleitung für die erste Probe

Ziel: den Abgleich einmal gefahrlos ausprobieren, **bevor** dein echter Spielstand daran hängt.
Dafür nimmst du einen Testordner und eine leere Wegwerf-Ablage bei GitHub. Dein echter
Kampagnenordner bleibt dabei unberührt. Nimm dir eine halbe Stunde, nicht kurz vor einem Abend.

## Vorbereitung

1. Wayfarer 0.1.3 installieren (Doppelklick auf
   `D:\Wayfarer\src-tauri\target\release\bundle\nsis\Wayfarer_0.1.3_x64-setup.exe`).
2. Einen leeren Ordner anlegen, zum Beispiel `C:\Users\Mattes\Documents\Wayfarer-Probe`.
3. Wayfarer starten, „Neu beginnen“ mit diesem Ordner. Ein paar Dinge anlegen (zwei Personen,
   einen Ort, eine Notiz) – nichts Echtes.

## Teil 1: Einrichten (Windows-PC)

4. Einstellungen → **Abgleich** → „Abgleich einrichten“ → „Das ist mein erster Rechner“.
5. Der Anleitung in Wayfarer folgen. Bei GitHub:
   - eine neue, **private** Ablage anlegen, Name zum Beispiel `wegwerf-probe`
     (nicht `spielstand-elaris` – die ist später für den echten Spielstand);
   - einen Zugangsschlüssel erzeugen, der **nur** für diese Ablage gilt.
   Den Schlüssel fügst du selbst in Wayfarer ein – gib ihn niemandem weiter, auch mir nicht.
6. Wayfarer sollte die Ablage beim Namen nennen und dann hochladen.
   **Bitte notieren:** Stimmen die Beschriftungen der Anleitung mit dem überein, was GitHub dir
   zeigt? Wo nicht, schreib mir das Wort, das bei GitHub steht.

## Teil 2: zweiter „Rechner“ (noch am selben PC)

7. Wayfarer schließen. Einen zweiten leeren Ordner anlegen (`Wayfarer-Probe-2`).
8. Wayfarer starten, auf dem Startbildschirm „Spielstand vom anderen Rechner holen“ mit diesem
   Ordner. Danach sollte dort derselbe Stand sein wie im ersten Ordner.
9. Hier etwas ändern, schließen, den ersten Ordner öffnen – kommt die Änderung an?
10. Einen Widerspruch bauen: in beiden Ordnern dieselbe Person verschieden ändern. Das Zeichen
    unter „Gespeichert“ sollte „Abgleich braucht dich“ sagen. Draufklicken und entscheiden.

## Teil 3: aufräumen

11. In beiden Testordnern Einstellungen → Abgleich → „Abgleich trennen“, **mit** Haken bei
    „Auch den Zugangsschlüssel entfernen“.
12. Die Wegwerf-Ablage bei GitHub darfst du danach löschen.

## Danach

Sag mir, wie es lief – besonders alles, was unklar war oder anders aussah als beschrieben.
Erst wenn das hier sauber läuft, kommen das MacBook und dann dein echter Spielstand (vorher
immer „Sicherung herunterladen“).
